# Breast Cancer Classification Using Machine Learning

## 1. Problem Statement

This project compares five supervised machine learning classifiers to predict whether a breast tumour is benign or malignant using diagnostic features.

This is an educational classification project and is not intended for clinical diagnosis.

## 2. Dataset Description

- **Dataset:** Breast Cancer Wisconsin (Diagnostic)
- **Source:** https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic
- **Records:** 569
- **Input features:** 30 numerical diagnostic features
- **Target:** `diagnosis` (B = benign, M = malignant)
- **Preprocessing:** The ID column is excluded from model inputs. The target is encoded as B = 0 and M = 1.
- **Data split:** 80% training and 20% testing, using stratification and random state 42.

## 3. Models Implemented

1. Logistic Regression
2. Decision Tree Classifier
3. K-Nearest Neighbors (KNN)
4. Gaussian Naive Bayes
5. Support Vector Machine (SVM)

## 4. Evaluation Metrics

The models are evaluated using:

- Accuracy
- ROC-AUC
- Precision
- Recall
- F1-score
- Matthews Correlation Coefficient (MCC)

The positive class is malignant (M = 1).

## 6. Observations

Use the comparison table above to identify which model performs best for the metric most relevant to the task.

For a medical screening context, malignant-class recall is particularly important because it measures the proportion of malignant cases correctly identified. Accuracy alone may not be sufficient to compare classification models.

This is an educational analysis and is not a clinical recommendation.
